# UCI Bike Sharing data

`hour.csv` is the hourly Bike Sharing dataset from the UCI Machine Learning
Repository:

- Hadi Fanaee-T (2013), *Bike Sharing*
- <https://doi.org/10.24432/C5W894>
- License: CC BY 4.0

The application uses `cnt` as the count outcome and standardized `temp` as
the treatment. It excludes `atemp`, `casual`, and `registered` from the
analysis.
